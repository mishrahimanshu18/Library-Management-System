# Library Management System
A full-stack **Library Management System** built with **React.js, Node.js, Express.js, and MongoDB**. This application helps manage books, users, book issuing, returns, and fines through a clean and responsive interface.

---
## Features

- 🔐 User Authentication (Login & Signup)
- 👨‍💼 Admin Dashboard
- 👤 User Dashboard
- 📖 Add, Update & Delete Books
- 📚 Browse Available Books
- 🔍 Search Books
- 📥 Issue Books
- 📤 Return Books
- 💰 Fine Management
- ✏️ Edit User Profile
- 📱 Responsive Design

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/shivamraj82182/Library-Management-System.git
```

### 2. Go to project folder

```bash
cd Library-Management-System
```

### 3. Install Frontend Dependencies

```bash
cd Frontend
npm install
```

### 4. Install Backend Dependencies

```bash
cd ../Backend
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside the **Backend** folder and add:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

### 6. Run Backend

```bash
npm start
```

### 7. Run Frontend

```bash
cd ../Frontend
npm run dev
```
